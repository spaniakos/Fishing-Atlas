# Contributing

Thanks for helping build Fishing Atlas.

- Open an issue for API compatibility bugs or new features.
- Use feature branches and pull requests. Keep changes small.
- Target Lua 5.1 syntax and avoid APIs not verified on WoW Forever.
- Run `lua5.1 tests/test_storage.lua`, `lua5.1 tests/test_commands.lua`, and `python3 scripts/validate.py`.
- Include or update tests for storage, parsing, and data processing.
- For live-client behavior, document the client build and exact reproduction steps.
- Never introduce automatic fishing bots or synthetic input loops.
- Only submit code and images you have the right to license under GPL-3.0-or-later, with clear attribution where needed.
- Mark uncertain catches, vendor locations, and recipes as provisional.

By contributing you agree to license your contributions under GPL-3.0-or-later.
