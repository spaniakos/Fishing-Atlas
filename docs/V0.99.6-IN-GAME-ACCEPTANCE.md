# FishingAtlas v0.99.6: Forever client acceptance gate

Target UI: WoW Forever interface **16001**. The in-game test report on
2026-11-14 was client **1.60.1.70938**; the original catalog/source geometry
was extracted from **1.60.1.70888**. This difference is a compatibility risk,
not proof that an individual source or map art tile is invalid.

## Verified by automated checks

- `FishingAtlas.toc` declares `IconTexture` pointing at the existing
  `Art/atlas-emblem.tga`.
- The top and sidebar both offer Fish and Items as distinct navigation targets.
- Fish includes all indexed fishing catches/pool loot/reference water species.
  Item category collects relevant Cooking ingredients/products, lures and poles;
  a creature drop or vendor sale alone does not imply the item is catchable.
- Global search navigates by immutable item/spell/NPC/map ID and retains an
  exact record that is absent from the destination's ordinary list.
- Item Name appears above Item ID for Items, Fish, and Gear.
- Equipment source tabs distinguish vendors, creature/object loot, recipes and
  quest rewards. Historical records are NEVER presented as confirmed on Forever.
- Offline fishing-only audit has the complete indexed source matrix in
  `docs/FISHING-SOURCE-AUDIT.md` and its JSON twin in `database/audit/`.
- Map tile layout, partial-art coverage, and fallback selection are tested.
- Secret tooltip values and unsupported trade-skill events do not abort addon
  initialization.

## In-game acceptance checklist (required before merge/tag)

1. Completely replace `Interface/AddOns/FishingAtlas` with the latest CI ZIP.
   Back up `WTF/Account/.../SavedVariables/FishingAtlas.lua` first.
2. Confirm Fishing Atlas shows its own icon in the WoW AddOns window.
3. Enable Lua errors using `/console scriptErrors 1` and `/reload`.
   Run `/fa diagnose`. No startup exception is acceptable.
4. Check BOTH Fish and Items from BOTH top navigation and left sidebar.
   Fish should include fishing-observed non-fish loot, not all vendor goods.
5. Search globally for another fish, Arcanite Fishing Pole, a recipe, a vendor,
   and a school. Click each result. The selected ID MUST match the clicked ID,
   not the first row of its new category.
6. In the center inspector, confirm Item Name appears before Item ID.
7. Check source cards: Big Iron Fishing Pole (#6367) historically comes from
   Shellfish Trap object loot, Blump Family Fishing Pole (#12225) from a quest,
   Aquadynamic Fish Attractor (#6811) from Engineering/reference vendors,
   and Arcanite Fishing Pole (#19970) from Master Angler (#8193). The relevant
   tabs must not claim these sources are currently confirmed Forever drops.
8. Check World Map, Expand, TomTom, and the in-panel art for Darnassus (1457),
   Darkshore (1439), Deadwind Pass (1430) and Ironforge (1455). The native map
   is the preferred fallback if client textures are incomplete.
9. Run `/fa mapdebug 1439`, `/fa mapdebug 1430`, and `/fa mapdebug 1457`.
   Record reported art layer and valid/expected texture counts. Compare with
   actual native World Map artwork. If native map ALSO has gaps, inspect
   `Logs/AsyncFile.log` for missing build-manifest map texture entries.
10. Check active-school and all-probable modes, plus mouseover errors and
    `/reload` persistence. Never classify historical school spawn candidates
    as live just because they appear in the reference map.

## Nov 14 follow-up: full base IDs are not visual coverage

The player's real client reported **12/12** numeric base texture IDs for
Darkshore (1439), Deadwind Pass (1430), and Darnassus (1457), while the embedded
preview still had opaque/dark gaps. Numeric map file references alone do not
mean all terrain is visible. The new map preview now requests
`C_MapExplorationInfo.GetExploredMapTextures(mapID)` and composes its
character-specific exploration art over the base tiles, with clipping.
`/fa mapdebug 1439` reports both base references and explored-overlay tile
counts so we can distinguish unexplored fog from a rendering failure.

Global search has also been changed to atomic category navigation. An EditBox
`SetText("")` fires `OnTextChanged` on the real client, which the previous
direct `selectCategory()` unit tests did not simulate. The new smoke test
actually types, clicks a result row, checks the exact selected ID and checks
subsequent refreshes.

**Validation still required on build 70938:** repeat clicks for two different
fish and an unindexed fishing pole from global search, inspect the new
`/fa mapdebug` overlay counts and compare the preview to the native world map.

## Map art limitation

`C_Map.GetMapArtLayerTextures` can return no textures, incomplete texture lists,
or texture IDs whose assets cannot be resolved by the installed game build.
A Lua addon cannot reconstruct a missing Blizzard map tile from an item ID
or from CMaNGOS spawn coordinates. The preview requests client art, retries
asynchronous loading a bounded number of times, exposes /fa mapdebug, and
uses the native World Map as the fallback for incomplete art.

**Release gate:** green CI is necessary but NOT sufficient. Do not merge,
tag or call maps corrected until the four in-game art samples pass.
