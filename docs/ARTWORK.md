# Fishing Atlas original artwork

Fishing Atlas uses original custom raster assets made for this project, not repackaged Blizzard or other addon textures:

- `Art/atlas-emblem.tga` — fishing-themed compass/fish badge for minimap and header (128×128, transparent background)
- `Art/lakeshore-banner.tga` — atmospheric sunset water header (512×128)
- `Art/deepwater-background.tga` — low-contrast deep-water/compass texture (512×512)
- `Art/bronze-button.tga` — bronze/blue UI button plate (256×64)

All are uncompressed 32-bit TGA with top-left origin, suitable for the WoW UI texture loader. They are included in the installable ZIP and validated in package tests. These files are original Fishing Atlas assets, covered by the repository's GPL-3.0-or-later license.

The graphical design experiments are separate mockups. Their example map pins, fish locations, counts or verification badges are **illustrative only**; they are not an authoritative source for data loaded by the addon.
