# Fishing Atlas v0.99.7: Forever in-game acceptance

Target: WoW Forever interface 16001. Record the actual client build.

Install: Back up SavedVariables, replace the complete FishingAtlas folder with
the CI artifact from draft PR #22 (not the previous 0.99.6 ZIP), enable
/console scriptErrors 1, then /reload and /fa.

The release fixes missing map pins and adds a guarded parent-map underlay.
A 12/12 tile load does not prove every pixel in Blizzard art is painted.
